Publish these files under `personal-desk/` in `AzmolFK/AzmolFK.github.io`. The portfolio homepage and its assets do not need changing.

If Google requests ownership verification, add `https://azmolfk.github.io/` as a URL-prefix property in Google Search Console using the Google account that owns/edits the Cloud project. Select HTML-file verification and add the exact file Google supplies to the repository's publishing root. Keep that verification file published. Do not invent a verification token. You may already have a verified property; check first.

After the required branding information saves, return to Audience and try Publish app. Personal use can qualify for a verification exception, but Google controls publishing and verification eligibility. These pages do not guarantee approval.
